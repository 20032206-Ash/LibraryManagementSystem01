# 📚 Library Management System

A full-featured Library Management System built with ASP.NET Core MVC and SQLite.

## 🌟 Features

### 🔐 Authentication
- Role-based login (Librarian & Member)
- Secure registration system
- Cookie-based authentication

### 👨‍💼 Librarian Features
- 📊 Interactive dashboard with statistics
- 📚 Add, edit, and delete books
- 👥 Manage library members
- ⚙️ Track all borrowings
- 📜 Configure borrowing policies

### 👤 Member Features
- 📊 Personal dashboard
- 🔍 Browse books with search & filters
- ✅ Multiple book reservations
- 🔖 Borrow and return books
- 🔄 Renew borrowings
- 📜 View borrowing history
- 👤 Manage profile

## 🛠️ Technology Stack

- **Framework:** ASP.NET Core 8.0 MVC
- **Database:** SQLite
- **ORM:** Entity Framework Core
- **Frontend:** Bootstrap 5, HTML5, CSS3
- **Authentication:** Cookie-based with Claims
